# Usage limit artwork

Unmodified SVG graphics from [Twemoji v16.0.1](https://github.com/jdecked/twemoji/tree/v16.0.1/assets/svg), by Twitter and other contributors. Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); full text in LICENSE-GRAPHICS.

The fire 🔥 follows a usage pace of 2x (once) or 4x (twice). It's the fallback for the Mac's Apple emoji (bridge/widgets/emoji.js), and three of them stand in for the Mac's 💀 at a usage window's limit.
